# Frozen 067. 겨울왕국으로 영어 귀뚫기 영상입니다. 영어 공부에 최고죠.

- **Video URL:** https://www.youtube.com/watch?v=wiQpAXqOztk

## Script & Explanation

Let the storm rage on...
폭풍은 계속 맹위를 떨치게 두고...
(폭풍 몰아쳐도)

My power flurries through the air into the ground.
내 힘은 하늘과 땅에서 흩날리네.
(내 힘은 눈보라로 세상을 덮고)

My soul is spiraling in frozen fractals all around.
내 영혼은 모든 얼어붙은 도형 속에서 솟아오르네.
(내 영혼 휘몰아치며 꽁꽁 얼려버리네)

And one thought crystallizes like an icy blast.
하나의 생각이 얼음 폭발처럼 결정체를 이루네.
(내 마음 가는 대로 모두 얼려버리네)


*rage : 맹렬히 계속되다
*flurry : 흩날리다
* spiral : 나선형(으로 움직이다)
* fractal : 프랙털, 분열도형
*crystallize : 결정체를 이루다
* blast : 폭발
