# Frozen 005. 잠자는 영어를 깨워드립니다. Wake up. Wake up!

- **Video URL:** https://www.youtube.com/watch?v=mev8KkQodXo

## Script & Explanation

Elsa. Psst!
언니. 언니야! 
(Elsa는 사람이름, 즉 고유명사입니다. 다만 여기서는 언니라고 번역했습니다. Psst!는 남에게 관심을 끌기 위해 부르는 감탄사입니다. 한국어로 ‘이봐!’ 정도 되겠죠.)

Elsa! (GRUNTS)
언니! (grunt는 투덜거리며 말하다. 대본의 지문이라고 보시면 됩니다.)

Wake up. Wake up. Wake up!
일어나. 일어나. 일어나라고!

Anna, go back to sleep.
안나야, 좀 더 자라. (안나, 잠자러 가!)
