# Frozen 029. There'll be magic. 영어가 들리는 마법같은 영상입니다.

- **Video URL:** https://www.youtube.com/watch?v=49XWaUpjo1E

## Script & Explanation

But then we laugh and talk all evening,
그리고는 저녁 내내 웃으면서 얘기하겠지. 

Which is totally bizarre.
굉장히 이상해.

Nothing like the life I've led so far.
내 생에 거기까지 가 본 적이 없지.

For the first time in forever, 
내 생에 첨이야. 

There'll be magic, There'll be fun.
그건 마법일 거야. 재밌을 거야.

For the first time in forever, 
내 일생에서 처음이니,

I could be noticed by someone.
누군가에 의해 알려질 수도 있어.



*bizarre : 기이한, 특이한
*Lead - led : 인도하다, 이끌다
